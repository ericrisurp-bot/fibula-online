# Fíbula Online — Etapa 1

Protótipo 2D de sobrevivência em ondas, feito com React, Vite, TypeScript e Canvas 2D puro.

## Requisitos
- Node.js 20 ou superior
- npm

## Como rodar
```bash
npm install
npm run dev
```
Abra o endereço local informado pelo Vite.

## Controles
- PC: WASD ou setas para mover; C alterna a câmera; 1, 2 e 3 trocam a arma de teste.
- Celular: D-pad na tela para mover; botões para alternar câmera e arma.
- Mouse/toque: botões da interface.

## Etapa 1
Mapa fechado com câmera, jogador slime encapuzado, espada/cajado/arco, slimes perseguidores, ondas crescentes, XP, níveis, tela de derrota e reinício.

Esta etapa não inclui login, banco de dados, Supabase, lobby, amigos, multiplayer, forja, itens, classes ou outros tipos de slime.
